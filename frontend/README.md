# VulnSight frontend

React + TypeScript + Tailwind CSS frontend for VulnSight.

See the root [`README.md`](../README.md) for setup and run instructions.

```powershell
npm install
npm run dev
```

The development server runs at <http://127.0.0.1:5173> and proxies `/api` to
the FastAPI backend at <http://127.0.0.1:8000>.
